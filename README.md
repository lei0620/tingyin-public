# 听音 · 对外版

把自己收藏的音乐，听成喜欢的样子。

[下载听音对外版 1.0.0](https://github.com/lei0620/tingyin-public/releases/download/v1.0.0/Tingyin-Public-1.0.0.apk) · [发布记录与校验摘要](https://github.com/lei0620/tingyin-public/releases/tag/v1.0.0) · [使用说明](docs/USER_GUIDE.md)

Android 8.0 起的自有音乐播放器，连接本地文件、个人 HTTPS WebDAV 和兼容 OpenSubsonic 的 NAS / Navidrome。听音不提供版权曲库，音乐需要自己准备。

基础播放、导入、搜索、收藏、队列、同步歌词与纸间主题免费，无需注册。高级体验包含暮色／玫瑰主题、专注歌词、智能歌单、听歌记录和 WebDAV 离线保存，可以先预览主题，再决定是否一次解锁。

高级权益用兑换码交付，一份授权用于一台安装设备，换机用购买恢复凭证。签名凭证可离线验证30天，之后联网刷新，不是每30天重新付费。买断不包含版权曲库或云存储。本发布没有微信／支付宝商户自动支付入口。

本应用与个人自用版包名、签名、数据和更新渠道分离，可以并存安装。请下载发布页中的 `Tingyin-Public-1.0.0.apk`；安装包 SHA-256：

```text
36b84028293796205cef6ed6670967db83226a69f7f0f3f1fd9f63a22967fb90
```
