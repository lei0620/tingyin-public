# 听音对外版使用说明

听音是Android自有音乐播放器，不提供版权曲库。基础功能免费，不用先注册。首次启动可查看隐私说明和使用约定，同意后进入播放器。最低Android8.0；先用自己的文件和服务器确认适配。

## 把自己的歌放进来

首页右上角“＋”打开添加音乐，选择“本地文件→选择歌曲”，在系统文件选择器中选择一首或多首音频。听音保存播放副本，原文件保留。进入“曲库”可按歌曲、歌手或专辑搜索，点击歌曲开始播放。

首页的演示曲由本项目程序合成，用于了解操作，不包含商业歌曲。正式使用时可选择自己的音频。

在歌曲行点击爱心可收藏；“曲库→喜欢”查看收藏。底部迷你播放器可播放／暂停和切歌，点击歌曲区域打开完整播放页。完整页提供进度、上一首／下一首、随机、循环、收藏和队列；右上角睡眠定时可选择15、30或60分钟后暂停。

## 连接个人WebDAV

“我的→我的音乐来源→连接我的WebDAV”，填写自己的HTTPS音乐目录、用户名和密码，选择“验证并连接”。服务器需支持PROPFIND目录浏览和设备信任的有效HTTPS证书。需要登录网页、重定向或OAuth授权的云盘地址，不能直接当作WebDAV目录使用。

连接后可进入文件夹、刷新、返回根目录或更换来源。目录中的音频可免费播放；高级体验可以点击单曲“离线保存”。单曲上限512MB，单目录上限五千条，当前来源索引最多一万首，较大的曲库可选择较小的目录。

“曲库→已离线”包含本地音频和已下载的WebDAV歌曲。断开WebDAV后，来源密码会移除，已下载的歌曲及离线索引仍保留。高级权益暂时无法刷新时，已有本地音频仍可通过基础播放器播放。

## 连接NAS / Navidrome

“我的→我的音乐来源→连接我的NAS”，填写自己的HTTPS服务器地址和账号，验证后连接。服务需兼容OpenSubsonic的搜索分页与原始ID播放接口；本版不是任意NAS协议客户端。服务器和账号不同，曲库索引与歌曲标识分开保存。

NAS来源用于直接播放。WebDAV离线保存属于另一项能力，不能把“能连接NAS”理解为所有NAS歌曲都可一键离线。最大来源索引为五万首，超出时可改用较小的WebDAV目录。

## 歌词、外观与高级体验

在播放页选择“歌词→导入LRC”，为当前歌曲选择UTF-8格式的LRC文件，单文件不超过256KB。基础同步歌词免费；高级体验提供专注排版。听音不自动抓取商业歌词，也不把导入歌词上传到权益服务。

“我的→外观与主题”可选择免费的纸间主题，并预览高级主题。暮色、玫瑰主题和专注歌词、智能歌单、听歌记录、WebDAV离线保存属于同一份高级权益。智能歌单依据本机收藏、加入时间及重听情况生成；听歌记录保存在本机。

## 兑换与换机恢复

应用不内嵌微信或支付宝收款。若已从真实销售渠道取得兑换码，在“我的→了解高级体验”填写完整TY1兑换码并兑换。成功后选择“保存购买恢复凭证”，通过系统选择器保存文本文件，妥善保管。

一份授权用于一台安装设备。更换手机、清除数据或重装后，可在高级页选择“恢复购买”，填写之前保存的恢复凭证。原安装不能继续联网刷新，已签发的离线凭证最多保留至原来的有效期。兑换码是首次交付凭证，不能代替换机恢复凭证。

高级签名凭证可离线验证30天，之后需要联网刷新，不是每30天重新收费。网络超时可安全重试原码；已有购买可选择刷新权益。未激活码的有效期以销售渠道交付说明为准，当前工具默认为发码后365天。

不要把兑换码、恢复凭证或服务器密码发到公开评论和问题区。恢复凭证遗失时通过原订单联系销售方核对；应用没有邮箱账号自动找回功能。退款由原销售渠道办理，退款撤销不能远程删除音频或立即擦除已签发的离线凭证。

## 数据和支持

来源密码使用Android Keystore保护。曲库、音频、歌词、收藏和收听记录不上传到权益服务。系统通知权限用于播放控制，可以拒绝。完整处理范围见应用内隐私说明。

卸载或清除应用数据会删除本机副本和设置，原音频文件保留；操作前先保存原音频和购买恢复凭证。当前没有跨设备曲库同步，也没有逐曲删除本机副本的管理入口。

“我的→下载与更新”打开独立对外版发布页。软件问题可在 [听音对外版问题区](https://github.com/lei0620/tingyin-public/issues) 提交不含敏感信息的描述；购买和退款请通过原订单渠道处理。
